SWEETY’S 3D-STYLE BIRTHDAY WEBSITE

Personalized details:
- Birthday name: Sweety
- Birthday date: 25-11 (25 November)

HOW TO RUN ON WINDOWS / VS CODE
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. If you have the Live Server extension, right-click index.html and choose “Open with Live Server”.
4. Click “Click here to enter”, blow the candle, and continue to the wishes page.

PROJECT FILES
- index.html: Welcome page personalized for Sweety.
- wishes.html: Birthday cake and blow-the-candles interaction.
- celebration.html: Birthday wishes, photo upload and celebration effects.
- style.css: Pink/dark theme, animations and 3D-style visual effects.
- script.js: Candle, confetti, emoji burst and photo upload interactions.

NOTES
- The 3D look is created with CSS perspective and transforms; no 3D engine is required.
- Choose a photo on the final page to display it in the frame. The photo is shown locally in your browser and is not uploaded to a server.
- You can click the birthday message text on the final page to edit it.
- Google Fonts need an internet connection; the website itself runs locally.
